CarO Webshop Project Conventions
================================

Project Overview
----------------

**CarO** is an online webshop dedicated to selling car parts. Its target audience includes customers of all ages within the Dutch market (The Netherlands).

Scope and Features
------------------

*   **Product Listing:** Fetch product data via a third-party API.
    
*   **Product Categories:** Organize products by categories for easier navigation.
    
*   **Shopping Cart:** Allow users to add, remove, and update products in their cart.
    
*   **Online Checkout:** Enable users to purchase items directly through the webshop.
    
*   **Integrations:**
    
    *   Third-party API for product information.
        
    *   Payment gateway integration (to be added in the final stage).
        

Technology Stack
----------------

*   Backend and frontend technology choices are flexible but should prioritize fast computation and strong community support. Suggested options include:
    
    *   ASP.NET
        
    *   JavaScript
        
    *   PHP
        
*   Use MVC (Model-View-Controller) file structure for logical organization.
    

Coding Standards and Conventions
--------------------------------

*   Code as a senior developer with clear, concise comments explaining key logic (avoid overly long comments).
    
*   Use professional formatting and indentation for readability.
    
*   Adopt logical and consistent file and naming conventions aligned with the MVC structure.
    

Development Workflow
--------------------

*   **Local Setup:** Running the project locally should serve the website on localhost.
    
*   Use Git for version control.
    
*   Before committing and pushing code to remote branches, obtain explicit confirmation ("GO"). Do not commit or push without permission.
    
*   Testing and deployment procedures should be defined as the project progresses.
    

Collaboration Protocols
-----------------------

*   Use Git branching for feature development and bug fixes.
    
*   Always request permission before pushing changes to shared remote branches.
    
*   Conduct code reviews and pull request approvals as part of the collaboration process.
    

Frontend Design Skills Reference
--------------------------------

*   Please refer to the **\[Frontend\_Design\_Skills.md\]** file for detailed guidance on frontend design principles and best practices.
    
*   Highlighted topics include responsive design, UI/UX consistency, and accessibility.
    

Additional Guidelines
---------------------

*   Prioritize accessibility, performance, security, and SEO throughout development.
    
*   Follow standard web accessibility guidelines (e.g., WCAG) to ensure inclusivity.
    
*   Optimize website performance and loading times.
    
*   Secure user data and payment processes rigorously.
    
*   Implement SEO best practices for better search engine visibility.
    

For questions or clarifications, please contact the project lead before proceeding with major changes.

_This document serves as the primary guide for developers contributing to the CarO webshop project._
