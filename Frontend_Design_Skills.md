Frontend Design Skills for CarO Webshop
=======================================

Core Frontend Skills
--------------------

*   Focus on **JavaScript** and a **CSS framework** for building the frontend.
    
*   Emphasize writing **easy-to-read** and **fast-to-compute** code for optimal performance.
    

Design Principles
-----------------

*   Design must be **responsive** and usable on all devices: phones, laptops, tablets.
    
*   Ensure the interface is **easy to use**, **understandable**, and **accessible** for everyone.
    
*   **Color schemes** and **typography** are defined in the project’s assets file (to be provided).
    

Accessibility
-------------

*   Provide the ability to **change website language** between Dutch (NL) and English (EN).
    
*   Include a **theme toggle** to switch between Light/Bright mode and Dark mode.
    
*   Additional accessibility features like keyboard navigation and screen reader support may be added later.
    

Performance
-----------

*   Prioritize **fast loading** times through efficient frontend coding and optimizations.
    

SEO Best Practices
------------------

*   SEO practices like semantic HTML, meta tags, and structured data will be added in future updates.
    

Tools & Libraries
-----------------

*   Specific frontend development tools (linters, build tools, testing libraries) will be documented later.
    

Collaboration & Workflow
------------------------

*   Follow **best practices** for frontend development and Git workflows.
    
*   Refer to the main **Project\_Conventions.md** file for overall project guidelines and collaboration protocols.
    

_This document serves as a guide for frontend developers contributing to the CarO webshop project, ensuring consistency, usability, and performance._
